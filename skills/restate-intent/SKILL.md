# Restate Intent

Restate my intent before continuing.

- In your own words, state what the user wants to achieve and which problem they want to solve.
- Keep it to a few short sentences. Explain the goal, not a list of your next actions.
- Use the conversation's current scope and constraints. Apply the user's latest corrections.
- Separate stated facts from any assumption that could change the result. Do not invent goals or requirements.
- If a missing detail changes the work, ask one focused question before doing work that depends on it.
- Otherwise, continue the requested work after the restatement. Do not add a confirmation step.
- If the user asks only for a restatement, stop after it.

Source: [Matt Pocock's post](https://x.com/mattpocockuk/status/2105628270930845990).

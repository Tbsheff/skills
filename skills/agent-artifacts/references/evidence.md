# Evidence and provenance

Important claims should trace to a file, line range, commit, log event, metric, dataset, issue, interview, or user statement.

## Source entries

Use the source list to record:

- a concise label;
- an exact location or URL when available;
- a revision, commit, date, or retrieval boundary;
- a note explaining what the source establishes.

## Distinguish three things

- **Observed fact:** directly supported by the source.
- **Inference:** a conclusion drawn from multiple facts; label the inference.
- **Recommendation or decision:** a judgment with an accountable owner or author.

Do not cite a broad repository when a specific file or commit supports the claim. Do not use a source’s reputation as a substitute for the mechanism visible in the evidence.

## Incomplete evidence

When evidence is missing:

- preserve the unknown;
- lower confidence;
- identify the next test or source needed;
- avoid a visually confident conclusion that the evidence cannot support.

# Evaluations

- `results.json` contains timings, classifications, and fixture metadata.
- `results.md` summarizes the three open-source evaluation cases.
- `papercuts.md` records problems found and the corresponding optimization.
- `artifacts/` contains the generated manifests, PR Markdown, local reports, command/API logs, screenshots, and short test video.

The fixture source repositories themselves are not distributed in this skill package.
